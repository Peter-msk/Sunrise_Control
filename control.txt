# update    = allow | block | required
#
# Evaluation order:
# 1. Read [global].
# 2. Read [product.<control_id>].
# 3. If the product section is absent, use global defaults.
# 4. If network access fails, use the last valid cached control until cache_ttl_seconds expires.
# 5. If no valid cache exists, use fallback_operation / fallback_update.
# 6. maintenance or block prevents normal application entry.
# 7. update=required means the product uses its OWN update contract and requires update
#    when current version is below minimum_version.
#
# minimum_version:
# - Semantic numeric version X.Y.Z
# - Blank means no minimum version is enforced.
#
# message:
# - UTF-8 text
# - Blank means the product uses its built-in default message.
