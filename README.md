# Sunrise Control

**현재 정책 형식: v1** · Sunrise Group 공통 운영 관리 저장소

Sunrise Control은 Sunrise Group 제품의 운영 상태와 업데이트 안내 정책을 일관되게 관리하기 위한 공통 저장소입니다.

## 1. 개요
각 Sunrise 프로그램은 자체 업무기능과 업데이트 기능을 유지합니다. Sunrise Control은 그룹 차원에서 제품별 운영 상태를 관리하고, 필요한 사용자 안내를 전달하는 역할을 합니다. 개별 프로그램을 대신 실행하거나 설치하는 별도 런처는 아닙니다.

## 2. 운영 목적
- 여러 제품의 운영 상태를 한곳에서 일관되게 관리합니다.
- 프로그램 점검 또는 사용 가능 여부를 제품별로 안내합니다.
- 제품별 업데이트 가능 여부와 필요한 안내를 관리합니다.
- 개별 제품의 기존 설치 및 업데이트 방식을 유지합니다.

## 3. 주요 기능
- 제품별 정상 운영·점검·사용 중지 상태 관리
- 제품별 업데이트 운영 정책 관리
- 최소 지원 버전 안내
- 프로그램 사용자에게 표시할 운영 메시지 관리
- Sunrise Group 제품의 운영 현황을 일관된 기준으로 유지

현재 연계 대상 제품에는 Sunrise Cleaner, Sunrise PDF PRO, Sunrise PDF Editor, Sunrise File Manager, Sunrise Finder, Sunrise Capture, Sunrise EIASS 등이 포함됩니다. 연계 범위는 제품별 개발·배포 상태에 따라 달라질 수 있습니다.

## 5. 사용방법
### 일반 사용자
1. 사용 중인 Sunrise 프로그램을 평소와 같이 실행합니다.
2. 프로그램에서 점검·업데이트·운영 안내가 표시되면 내용을 확인합니다.
3. 업데이트가 필요한 경우 해당 프로그램에서 제공하는 공식 절차를 이용합니다.
4. 제품 기능의 일반적인 사용법은 각 제품 저장소 README를 참조합니다.

### 운영 담당자
운영 정책은 저장소에서 별도로 관리하며, 각 제품의 실제 배포 버전 및 운영 상황에 맞추어 유지합니다. 변경 작업은 승인된 운영 절차와 담당자 권한에 따라 수행합니다.
