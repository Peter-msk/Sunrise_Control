# Sunrise Control

Sunrise Group 제품의 실행 및 업데이트 허용 여부를 중앙에서 관리하는 정책 저장소입니다. 일반 사용자가 별도 실행하는 프로그램이나 통합 런처는 아닙니다.

## 프로그램 목적

제품별 운영 상태와 업데이트 제어 정책을 일관된 형식으로 제공하면서, 실제 설치·업데이트·기능 실행은 각 Sunrise 제품의 고유 절차와 호환계약을 유지하도록 지원합니다.

## 지원 운영체제

- **정책 파일 자체:** 운영체제에 종속되지 않는 UTF-8 텍스트 형식
- **현재 주요 연동 대상:** Windows 10 / Windows 11 (64비트, x64)용 Sunrise 데스크톱 제품
- **별도 설치:** Sunrise Control 자체의 일반 사용자용 설치 프로그램은 필요하지 않습니다.

## 개발언어 및 주요 기술

- **정책 기술 형식:** INI 스타일의 UTF-8 텍스트 구성 파일(`control.txt`)
- **설명 문서:** Markdown
- **실행 언어:** 이 저장소는 실행 애플리케이션이 아닌 정책 저장소이므로 별도 실행용 프로그래밍 언어가 없습니다.

## 주요 기능

- 제품별 실행 허용·점검·차단 상태 정의
- 제품별 업데이트 허용·차단·필수 업데이트 정책 정의
- 최소 지원 버전과 사용자 안내 메시지 관리
- 전역 기본 정책 및 제품별 개별 정책 제공
- 연동 제품의 네트워크 장애 시 캐시·대체 정책 판단 지원
- 제품별 기존 업데이트 메타데이터·패키지 계약과의 역할 분리
